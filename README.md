A web application designed for **Hostel & Dining Mess Management**, facilitating daily thali menu browsing, student meal booking, meal plan subscriptions, and mess admin operations.

</div>

---

## 📌 Features

- 🍲 **Daily Menu & Thali Selection**: Browse Special Thali, Mini Thali, Executive Meal packages.
- 🔐 **Student Authentication**: Secure login and signup portals for hostel residents.
- 📊 **Mess Billing & Subscription**: Track monthly meal counts and attendance.
- 📱 **Responsive Design**: Compatible with mobile, tablet, and desktop viewports.

---

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/AbhishekNarwade/Mess-Management-System.git
   cd Mess-Management-System
   ```
2. Open `messmanagement.html` or `loginpage.html` in your web browser!
